# GitHub Achievement Lab

A public sandbox for exploring GitHub workflows and profile achievements.

## Solo achievements

- Quickdraw: close an issue or pull request within five minutes of opening it.
- YOLO: merge a pull request without a code review.
- Pull Shark: have two authored pull requests merged. Higher tiers require 16, 128, and 1,024 merged PRs.

## Achievements requiring outside participation

- Pair Extraordinaire: co-author a merged pull request with another contributor.
- Galaxy Brain: receive two accepted answers from other users in repository Discussions.
- Starstruck: have a repository reach 16 stars.
- Public Sponsor: sponsor open-source work through GitHub Sponsors.

## Historical and experimental badges

Arctic Code Vault Contributor and Mars 2020 Contributor were tied to historical snapshots. Heart On Your Sleeve and Open Sourcerer are unavailable experiments.
