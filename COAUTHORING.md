# Co-authored commit verification

This lab checks commit attribution using the repository owner’s two GitHub accounts, AmarsChandra and achandra2-chwy.

## Checklist

1. Author a commit with the primary account.
2. Add a blank line before the `Co-authored-by: Name <email>` trailer.
3. Use an email associated with the second GitHub account.
4. Open a pull request containing the commit.
5. Use a merge commit so the original attribution remains in the history.
6. Open the merged commit and verify that GitHub links both accounts.
7. Check the primary profile’s Achievements page for Pair Extraordinaire.

Pair Extraordinaire has known milestones of 1, 10, 24, and 48 co-authored merged pull requests. GitHub controls award processing.

[GitHub documentation: creating a commit with multiple authors](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors)
