# Contributing

This repository is a small GitHub workflow sandbox. Improvements to the achievement guide and reproducible observations are welcome.

## Pull requests

1. Create a branch for one focused documentation improvement.
2. Make the change and check the Markdown preview.
3. Open a pull request describing the improvement and how it was checked.
4. Merge only after confirming that the diff matches the description.

## Co-authoring

When two contributors work on a commit, credit the actual collaborator using their GitHub-linked name and email in a commit trailer:

```text
Co-authored-by: Contributor Name <github-linked-email>
```

Use the contributor’s real GitHub identity for shared work.

## Discussions

Use the Q&A category for real questions about repository workflows. Mark an answer accepted when it resolves the question. Galaxy Brain requires answers from one user to questions from another user.
